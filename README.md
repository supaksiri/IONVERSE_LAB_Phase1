# IONVERSE LAB — Phase 2: Smart Realistic 3D Lab

ทดลองสารละลายอิเล็กโทรไลต์ 12 ชนิด + น้ำกลั่น ต่อจาก Phase 1

## วิธีเปิด

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไป GitHub repository
2. Settings → Pages → Deploy from branch → main → /(root)
3. เปิดหน้า GitHub Pages ผ่าน Chrome/Edge (ต้องมีอินเทอร์เน็ตเพื่อโหลด Three.js จาก jsDelivr)

ทดลองในเครื่อง: `python3 -m http.server 8080` แล้วเปิด `http://localhost:8080`

## วิธีใช้

เลือกสาร → กด **⓪ เตรียมสาร 4 mL** (หรือคลิกบีกเกอร์/ขวดในภาพ 3D) → ลิตมัสแดงและน้ำเงิน → ต่อวงจร → จุ่มขั้ว (หรือคลิกขั้วใน 3D) → เปิดสวิตช์ (หรือคลิกหลอดไฟ) → เลือกประเภทสาร → บันทึกผล → ล้างขั้วก่อนทดลองสารต่อไป

ใช้เมาส์ลากฉากเพื่อหมุน / เลื่อนล้อเพื่อซูม และกด **มุมกล้อง** เพื่อกลับสู่มุมมาตรฐาน

## การเปลี่ยนแปลง Phase 2

- ฉากโต๊ะทดลอง 3D ด้วย Three.js: โมเดลบีกเกอร์แก้ว สารละลาย ขวดสาร ขั้วไฟฟ้า หลอดไฟ แหล่งจ่ายไฟ ปิเปต และแผ่นลิตมัส
- สถานะเตรียมสารมีแอนิเมชันระดับของเหลว, ขั้วไฟฟ้ายก-จุ่มและหลอดไฟเปลี่ยนแสงตามสัญญาณจาก engine
- Raycasting สำหรับคลิกวัตถุสำคัญในฉาก โดยยังมีปุ่มกดสำรอง
- กล้องแบบ orbit จำกัดระยะให้เหมาะกับการทดลอง
- คงสารทั้ง 12 ชนิด, Chemistry Engine, ลิตมัส, notebook/CSV และการทดสอบ 25 กรณีจาก Phase 1

## ข้อจำกัดตรงไปตรงมา

**Phase 2 เป็น 3D prototype ไม่ใช่โหมด photorealistic สำเร็จเต็มขั้น**: โมเดลเครื่องมือสร้างจาก geometry ด้วยโค้ด ยังไม่มีโมเดล GLB สแกนจริง texture 4K, realistic liquid pouring, fluid dynamics หรือระบบลากเครื่องมือแบบ 6DoF; การคลิกเตรียมสารทำให้ระดับน้ำเพิ่มอย่างนุ่มนวลแทนแอนิเมชันการเทเต็มรูปแบบ

Three.js โหลดผ่าน CDN จึงต้องมีอินเทอร์เน็ตครั้งแรก มิเตอร์เป็นดัชนีเชิงเปรียบเทียบ ไม่ใช่ µS/cm ที่สอบเทียบจริง; ภาพ 3D ไม่ใช่หลักฐานผลทดลองจริง

ไม่เชื่อม Google Sheets ในเฟสนี้ (กำหนดไว้ Phase 4) และการประเมินไม่ใช่การสอบเทียบทางห้องปฏิบัติการ
